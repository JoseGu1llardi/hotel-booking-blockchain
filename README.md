# Decentralized Hotel Booking System

## Overview

This project implements a blockchain-based hotel booking system that eliminates
intermediaries (OTAs like Booking.com) using smart contracts as an escrow layer.

## Technology Stack

- **Smart Contract:** Solidity ^0.8.19
- **IDE:** Remix IDE
- **Local Blockchain:** Ganache
- **Wallet:** MetaMask
- **Cryptography:** SHA-256 (integrity) + ECDSA (authentication)

## Project Structure

- `/contracts` - Solidity smart contracts
- `/docs` - Business model and technical documentation
- `/poster` - PowerPoint poster presentation
- `/screenshots` - Evidence of deployment and testing
- `/scripts` - Deployment and testing guides

## Key Features

1. Trustless booking between guest and hotel
2. SHA-256 hashing for booking integrity
3. ECDSA-based authentication via MetaMask
4. Automated escrow with check-in triggered payment
5. Transparent cancellation policy
